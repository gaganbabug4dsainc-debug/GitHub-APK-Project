# AI Assistant Multi-Platform Project

Yeh project ek universal AI assistant hai jo multiple platforms (Claude, Gemini, ChatGPT) se API key aur email login karke kaam karta hai.

## Features
- Multi-platform AI support (Claude, Gemini, ChatGPT)
- API key authentication
- Email login system
- Secure credential storage
- Universal chat interface

## Tech Stack
- Backend: Python/Node.js
- Frontend: React/Android
- APIs: OpenAI, Anthropic Claude, Google Gemini

## Setup
1. Clone repository
2. Install dependencies
3. Configure API keys
4. Run application

## Usage
Login with email ya API key dalke apne pasand ka AI platform select karo aur chat shuru karo. ni ni ni ni
